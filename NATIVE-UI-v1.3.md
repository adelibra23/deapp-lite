# Deapp Lite Android v1.3 — Threads-inspired Clean Shell

Pembaruan fokus pada rasa aplikasi sosial native yang lebih sederhana dan dekat dengan pola navigasi Threads, namun tetap memakai identitas Deapp sendiri.

## Perubahan utama

- Header sangat minimal: logo Deapp di kiri dan satu tombol menu fitur di kanan.
- Bottom navigation hanya berisi Beranda, Jelajah, Aktivitas, dan Profil.
- Tombol buat kiriman dipindahkan menjadi floating action button (+) di kanan bawah.
- FAB otomatis disembunyikan saat keyboard terbuka atau video fullscreen aktif.
- Menu fitur kanan atas membuka bottom sheet grid berikon: Profil, Pesan, Live, Video, Komunitas, Tersimpan, Deapp Tap, AI, Developer, Toko, Mini Game, dan Pengaturan.
- Native bottom sheet dapat ditarik ke bawah dari area sheet untuk ditutup.
- Modal web/composer juga dipoles menjadi draggable bottom sheet di APK: swipe ke bawah dari posisi scroll teratas untuk menutup.
- Composer trigger bawaan halaman Beranda disembunyikan di APK agar tidak ada dua tombol buat kiriman.
- Feed/home dipoles lebih flat: card, tab, divider dan shadow dibuat lebih sederhana.
- Scrollbar visual tetap disembunyikan tanpa mematikan kemampuan scroll.
- Palet shell lebih monokrom (putih/hitam) dengan biru Deapp hanya untuk aksi/progress utama.
- Splash tetap memakai logo Deapp.
- Live/WebRTC, upload file, kamera/mikrofon, download, fullscreen video, pull-to-refresh, offline screen dan server switching tetap dipertahankan.
