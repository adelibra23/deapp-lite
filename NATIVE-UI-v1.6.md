# Deapp Lite Android v1.6.0

Fokus pembaruan:

- Tidak ada flash, highlight, ripple, atau efek pressed browser saat mengetuk link/menu. Haptic native tetap dipakai sebagai feedback tak terlihat.
- Pusat Perizinan Android untuk Lokasi, Kontak, Notifikasi, Foto & Media, Mikrofon, Telepon, dan Kamera.
- Izin diminta satu per satu hanya setelah pengguna memilihnya atau saat fitur terkait membutuhkannya; tidak dipaksa saat aplikasi dibuka.
- Setelah endpoint `api/post_create.php` mengembalikan sukses, APK memainkan bunyi konfirmasi singkat.
- Pull-to-refresh memakai logo Deapp: logo mengikuti tarikan, lalu beranimasi selama refresh berlangsung.
- Tentang aplikasi diperbarui menjadi v1.6.0-lite · Build 7.

Tidak ada perubahan database Deapp.
