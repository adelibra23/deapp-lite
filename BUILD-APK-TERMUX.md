# Build APK di Android/Termux

Jika belum memiliki Android Studio, source Deapp Lite ini bisa dipindahkan ke komputer dan dibuild dengan Android Studio. Untuk build langsung melalui Termux, pasang JDK dan tool Android (aapt2/apksigner/dx atau Android SDK command-line tools), lalu compile project sesuai toolchain Android yang tersedia.

APK hasil build sebaiknya ditandatangani dengan keystore milik sendiri sebelum dibagikan ke pengguna lain.
